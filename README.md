# AIRETIA Reservation frontend (deployment repository)

This repository contains only the built static frontend for GitHub Pages.
The application source remains in the private repository `airi-13/Airetia-reservation-system`.

- Custom domain: `reserve.airetia.co.jp`
- Search indexing: intentionally discouraged via `noindex` in the source frontend.
- API: `https://api.airetia.co.jp` (backend must be deployed separately)
