## プロバイダー申請フローと書類の関係

```
申請者がシステムで入力・アップロードするもの
├── 基本情報入力（氏名・経歴・アピールポイント等）
├── 書類アップロード
│   ├── IDENTITY  : 身分証明書（画像/PDF）
│   ├── CONTRACT  : 署名済み業務委託契約書 [06] + NDA [08] + 反社誓約書 [09]
│   │               ※ 3書類をまとめて1PDFにするか、別々にアップロードするか要検討
│   └── BANK_INFO : 口座情報（画像/PDF）
└── 同意チェックボックス
    ├── 個人情報取扱い同意書 [07]（画面上でチェック）
    ├── 利用規約 [01]（登録時に同意済み）
    └── プライバシーポリシー [02]（登録時に同意済み）
```

> **実装上の注意**: 現在の仕様では`CONTRACT`は1ファイルのみアップロード想定。  
> 業務委託契約書[06]・NDA[08]・反社誓約書[09]をまとめた統合書類テンプレートの用意、または複数ファイル対応を検討してください。

## 要確認・未確定事項

| 項目 | 内容 |
|------|------|
| 運営会社情報 | 会社名・代表者名・住所・電話番号・メールアドレスを全書類に記入 |
| 管轄裁判所 | 第14条の[管轄地]を確定する |
| 振込先口座 | 特定商取引法表示の振込先を記入 |
| CONTRACTの仕様 | 複数書類（06+08+09）を1ファイルにまとめるか、システム対応するか |
| 消費税率 | 現在10%で記載。変更時は03を更新する |
| Phase2対応 | Stripe導入時に03・04の改訂が必要 |
| 弁護士レビュー | 全書類について法務専門家によるレビューを推奨 |
