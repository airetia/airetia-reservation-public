# 未成年者（お子様）利用に関する保護者同意書

> 関連文書: [01_terms_of_service.md](./01_terms_of_service.md) / [02_privacy_policy.md](./02_privacy_policy.md)

---

## 概要

本サービス「airetia」において、メンバー（保護者）が子どものアカウント（パーティシパント・CHILD）を登録する際に適用される同意事項です。

子どものアカウントを登録した時点で、保護者は以下の全項目に同意したものとみなします。

---

## 同意事項

### 1. 保護者責任

- 子どもに関するアカウント情報（氏名・性別・生年月日等）の正確性について、保護者が責任を負います。
- 子どもによる本サービスの利用（予約・受講）について、保護者が監督責任を負います。
- 子どもが本サービスを利用することによって生じた損害・トラブルについて、保護者が一次対応の責任を負います。

### 2. 個人情報の取り扱い

以下の子どもに関する情報が収集・利用されることに同意します。

| 情報 | 利用目的 |
|------|---------|
| 氏名・性別・生年月日 | サービス提供・予約管理 |
| 受講履歴・フィードバック | サービス品質向上・プロバイダーとの情報共有 |
| 要注意マーク・ペナルティ情報 | 適切なサービス運営のため |
| shared_note（受講者特徴メモ） | 予約実績のある全プロバイダー間での共有（サービス品質向上目的） |

詳細は [プライバシーポリシー](./02_privacy_policy.md) を参照してください。

### 3. プロバイダーへの情報提供

予約が確定した場合、担当プロバイダーに以下の最小限情報が提供されます。

- 提供情報：氏名・年齢・要注意マーク・担当プロバイダーによる指導メモ
- 非提供情報：住所・電話番号・メールアドレス

### 4. ペナルティの適用

子どもの無断キャンセルに対するペナルティは、子どものアカウント（パーティシパント）に対して適用されます（[利用規約第7条](./01_terms_of_service.md#第7条ペナルティ) 参照）。

### 5. 登録上限

1メンバーアカウントにつき、子どものアカウント（CHILDタイプ）は最大5名まで登録できます。

### 6. アカウント削除

子どものアカウントを削除する場合、進行中の予約がすべてない状態にしてください。有効な予約が残る状態での削除はできません。

---

## 保護者確認事項

子どもアカウントを登録する前に、以下を確認してください。

- [ ] 子どもが本サービスを安全に利用できる環境を整えること
- [ ] 子どもに本サービスの利用ルール（予約・キャンセル・受講マナー等）を説明すること
- [ ] 子どもの受講状況を定期的に確認すること
- [ ] 利用規約・プライバシーポリシーの内容を理解した上で登録すること
