⬡ Git チートシート

1人開発・2台PC運用　／　Windows（外） ↔ Mac（家）

毎日の作業フロー
1
git pull
作業開始前に必ず。最新状態にする
2
（作業）
コードを書く・修正する
3
git add .
変更ファイルをすべて対象にする
4
git commit -m "メモ"
何をしたか一言で残す
5
git push
GitHubに反映。作業終了のたびに
確認・修正コマンド
git status
現在の変更状態を確認
迷ったらまずこれ
git log --oneline
commitの履歴を一覧表示
git reset HEAD~1
直前のcommitを取り消す
push前のみ有効
git remote set-url origin <URL>
リポジトリ名変更後に
接続先URLを更新
ルールと注意
必須
作業開始は必ず git pull から
推奨
commitメッセージは内容がわかる言葉で
"修正" より "ログイン機能追加"
初回
プロジェクトに .gitignore を置く
bin/ .classpath .DS_Store を除外
NG
リポジトリを Public にしない → コードが全公開される
NG
長期間 push しない → ローカルとGitHubが乖離する
今不要
branch / merge / pull request は今のフェーズでは不要
